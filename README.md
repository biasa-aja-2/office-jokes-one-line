## How it works

`main.py` is pure-stdlib Python (imports `os` and `sys` only). It writes the
line above, deterministically and byte-identically on every run, to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set locally).
No network, no randomness, no trailing newline.

```sh
python3 main.py
cat /output/entry.txt
```
